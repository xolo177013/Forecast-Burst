Methodology

How to read this system

01
Forecast input

NWP fields (geopotential, moisture flux, vorticity, precipitation) are transformed into region-level features per cycle.

02
Bust detection

A calibrated classifier estimates P(bust) — probability that forecast error exceeds the historical threshold for that cell and lead.

03
Confidence field

Bust probability is inverted into an interpretable confidence value, spatially mapped at 1°×1° grid resolution.
